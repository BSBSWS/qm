# Qualitätsmanagement der Sozialwerk Sauerland GmbH

Dokumente des Qualitätsmanagements und die Standards, nach denen sie geschrieben und geprüft werden. Konzeptionen liegen in BSBSWS/SWSKonz, Leistungsbeschreibungen in BSBSWS/SWSlb, Texte der Öffentlichkeitsarbeit in BSBSWS/oeffentlichkeitsarbeit.

| Ordner | Inhalt |
|---|---|
| `standards/` | Standards für QM-Dokumente |
| `export/` | Word-Ausgaben; in `export/ablauf/` je Prozess das Ablaufblatt (Word, PDF, Bild). Erzeugen mit `sh tools/export-alle.sh` |
| `tools/` | Export nach Word (`export-docx.js`), Logo |
| `handbuch/` | QM-Handbuch: Gliederung (Dokumentenliste), Befunde, überführte Dokumente; Vorlagen in `handbuch/alt/` |
